# Промкровля — hero-секция (PoC для оценки качества кода)

Демонстрационная вёрстка hero-секции для корпоративного сайта на MODX.
Сделана как proof перед открытием Безопасной Сделки на FL.ru.

**Live demo:** https://ivanovkonstantin949-png.github.io/roman-modx-hero-poc/

## Стек

- HTML5, CSS3
- Без фреймворков, без сборщиков
- Шрифт Inter с Google Fonts
- Inline SVG для иконок

## Что внутри

- Sticky header: логотип, основная навигация, телефон, CTA-кнопка, бургер для мобилки
- Hero: eyebrow-бейдж, H1 с акцентным подчёркиванием, lede, два CTA (primary + ghost)
- Trust-strip: 3 ключевых цифры с разделителем
- Карточка quick-расчёта: select типа объекта, площадь, телефон, кнопка submit
- Marquee с маркерами доверия (ISO 9001, СРО, отгрузка по РФ)

## Адаптив

| Брейкпоинт | Поведение                                                       |
| ---------- | --------------------------------------------------------------- |
| ≥1080px    | Полная двухколоночная сетка                                     |
| 820–1080px | Скрыт телефон в шапке, ужата навигация                          |
| ≤820px     | Бургер вместо навигации, hero в одну колонку, full-width кнопки |

## Доступность

- `aria-label` на всех CTA и иконках
- `focus-visible` с оранжевым outline
- `prefers-reduced-motion` отключает marquee и transitions
- Семантические теги: `<header>`, `<nav>`, `<section>`, `<aside>`, `<form>`

## Интеграция с MODX

Hero уезжает в файл шаблона как есть. Динамика через стандартные сниппеты:

- Меню → `pdoMenu` с `&parents=0 &level=1`
- Телефон и CTA → системные настройки или TV
- Форма расчёта → `FormIt` + reCAPTCHA + email-хук
- Каталог в секциях ниже → `getResources` + чанки `tpl.product.card`
- Изображения → `phpThumbOn` для WebP с fallback

## Структура

```
.
├── index.html      ← разметка hero
├── styles.css      ← стили с CSS-переменными
└── README.md       ← этот файл
```

CSS-переменные сверху файла — палитра, радиусы, тени.
Менять одну строчку → меняется всё подключённое.
